# HUMANITY LEDGER

![HUMANITY LEDGER](docs/logo.png)

A purely deterministic enclave for humanity. Zero-knowledge cryptographic circuits ensure absolute sovereignty. No marketing. No tracking. Pure mathematics.

**Humanity Ledger** is an end-to-end encrypted, L2 ZK-rollup ecosystem settled on the Aztec Network. It provides an immersive, brutalist, and uncompromisingly private infrastructure for real-world asset tokenization (Studio Provenance), un-censorable peer-to-peer communication (Whale Chat), and sovereign financial tracking.

## Core Pillars
- **Zero-Knowledge by Default**: Powered by Noir and the Aztec Network. Your balances, transactions, and chat metadata are invisible to the sequencer.
- **Sovereign Identity**: Reclaim your digital self. Your EIP-191 signatures prove ownership, your ZK proofs assert validity.
- **Quantum-Resistant Foundations**: Preparing for the next epoch of cryptography with QDS (Quantum Defence Shield) tokenomics.
- **Swiss Brutalist Aesthetics**: Form follows mathematics. No unnecessary animations, no gradients. Just raw data and optical precision.

## Ecosystem Architecture

### 1. Portfolio Terminal
A multi-chain asset tracker that calculates your positions entirely locally in your browser. No centralized indexing server. Your API keys (Etherscan, Alchemy, Moralis) never leave your device.

### 2. Whale Chat
Peer-to-peer, E2E encrypted messaging using the XMTP protocol wrapped in Aztec ZK logic. Support for stealth payments, timed burning messages, and WebRTC encrypted video/voice calls that bypass traditional signaling relays.

### 3. Studio Provenance
Register real-world assets (art, real estate, IP) natively on L2. Generate un-forgeable cryptographic passports (certificates of provenance) that can be verified publicly without revealing the owner's identity.

## Getting Started

### Prerequisites
- Node.js >= 18.x
- pnpm >= 8.x
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/humanityledger/Humanity-Ledger.git

# Enter directory
cd Humanity-Ledger

# Install dependencies
pnpm install

# Start development server
pnpm dev
```
